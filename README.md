FunScriptCast 是安卓端**互动播放器与设备控制器**：通过蓝牙连接 ServeU / Vorze 设备，既可与 **HereSphere / DeoVR** 联动、为头显正在播放的视频自动加载并同步 `.funscript` 脚本，也内置了支持 **本地 / WebDAV / DLNA / SMB** 的播放器、**24 种中文预设动作模式**与 **AI 实时中文字幕**。

| 资源 | 链接 |
|---|---|
| 📥 APK 下载（Android 8.0+） | [Releases](https://github.com/wanfneg/FunScriptCast-Releases/releases/latest) |
| 🖥️ PC 端 Nexus（AI 字幕 + DLNA 服务器） | [FunScriptCast-Nexus](https://github.com/wanfneg/FunScriptCast-Nexus/releases/latest) |

主界面共五个页面：**连接**（设备与播放器连接、远程源配置）/ **视频**（内置播放器）/ **联动**（外部播放器控制台）/ **预设**（动作模式）/ **设置**。内置播放器与外部联动两种模式互斥，切换时 App 会弹窗确认。

## 一、连接设备

### 连接步骤

1. 打开设备电源，确保手机蓝牙已开启；
2. 进入「连接」页，点击 **扫描并连接**；
3. 连接成功后「当前设备」卡片显示 🟢 已连接；点击 **断开设备** 可断开；
4. 蓝牙未开启时 App 会弹窗引导前往系统设置。

> 首次启动建议按提示授予「所有文件访问」权限：本地浏览与脚本索引都会显著加快。

### 设备相关设置（设置页）

- **狂暴模式**：电机满功率运行，扭矩约提升 30%（需较新固件，开启前有确认弹窗）；
- **反转方向**：行程方向与脚本相反时使用；
- **伪装设备**：以 Vorze Piston 模式连接；
- **固件更新（OTA）**：设备连接 Wi-Fi 后在线升级；
- **延迟调整**：±10ms / ±100ms 微调脚本与画面同步（负值提前、正值滞后）；
- **手动控制位置**：拖动滑轨直接移动设备到指定位置；
- **跳过无动作部分**：开启后，脚本中连续无动作的段落超过设定时长（默认 60 秒）时自动快进跳过。

## 二、VR 播放器联动（HereSphere / DeoVR）

App 在局域网监听 TCP 端口（默认 **23554**），VR 播放器把播放进度实时推送给 App，App 自动加载配套脚本并驱动设备。**头显里播视频，手机上做控制器。**

### 通用步骤

1. 在 VR 播放器中开启远程控制（见下）；
2. 查出头显的 IP 地址；
3. 「连接」页顶部的 **播放器连接** 处填入 IP 与端口（默认 23554），点击 **连接播放器**；
4. 在「设置」页设定 **脚本文件夹**，并将配套 `.funscript` 放入该文件夹（也可配置远程脚本源，见第五节）；
5. 头显中开始播放，「联动」页出现脚本热力图，设备随视频同步运动。

### HereSphere

- 支持头显本地视频播放与 SMB 局域网视频播放；
- 打开 HereSphere → **User Settings** → **Advanced Settings** → 勾选 **Timestamp Server**；
- 点击 Timestamp Server 旁的刷新按钮，记录下方出现的 IP 地址；
- 回 App 填写该 IP（端口默认 23554），点击连接播放器。

### DeoVR

- 支持头显本地视频播放与 DLNA 局域网视频播放（DLNA 服务器使用 PC 端 [Nexus](https://github.com/wanfneg/FunScriptCast-Nexus/releases/latest)）；
- 打开 DeoVR → **Settings** → **Developer** → 勾选 **Enable Remote Control**；
- 查 IP：Quest「设置」→「Wi-Fi」→「详情」→「IP 地址」；Pico「设置」→「WLAN」→「添加网络」→「更多」→「IP 地址」；
- 回 App 填写该 IP（端口默认 23554），点击连接播放器。

### 进阶：在头显内直接控制

把本 App 装进头显，播放器 IP 直接填 `127.0.0.1`：

- Quest：「设置」→「实验性」→ 打开「多任务无缝处理」；
- Pico：暂无「多任务无缝处理」，不支持；
- 其他品牌：请自行测试。

### 联动页功能

- **脚本热力图**：全片动作强度一目了然，点击 / 拖动三角滑块即向播放器发送跳转；
- 显示当前脚本名称与加载状态、播放进度，可播放 / 暂停；
- **快捷动作**：待机缓动 / 一键急停 / 一键爆发；
- 设备行程与速度调节。

## 三、内置播放器

「视频」页内置播放器，播放视频 / 音频时同样自动加载同名脚本驱动设备。

### 视频源（四种）

| 源 | 配置 |
|---|---|
| **本地** | 选择「本地视频存放文件夹」 |
| **WebDAV** | 服务器地址（如 `http://192.168.1.5:5005/dav`）+ 账号密码 |
| **DLNA** | 自动扫描局域网媒体服务器点选，或手动填写设备描述地址 |
| **SMB** | 主机 IP + 共享名 + 账号密码（均可匿名） |

- **SMB 共享名可以留空**：留空时自动列出当前账号可访问的全部共享（含 `C$`~`H$` 盘符共享），点选进入即可；自定义共享名探测不到时手动填写；
- 密码等敏感配置加密存储在设备本地。

### 播放功能

- **格式**：视频 mp4 / mkv / mov / avi / webm / ts / wmv / flv 等；音频 mp3 / m4a / wav / flac / ogg 等（音频同样支持脚本联动）；
- **外挂字幕**：与视频同目录、同名的 `.srt / .ssa / .ass / .vtt` 自动挂载；内嵌字幕 / 音轨可手动切换；字幕样式（文字大小、垂直位置、颜色）可调；
- **播放列表**：打开某个视频即把所在目录作为播放列表，支持上一集 / 下一集、自动连播、循环三态（关 / 列表 / 单曲）；
- **续播记忆**：每 5 秒记录播放进度，「继续上次」一键接着看（看完的视频自动清除记忆，避免打开即跳过）；
- **倍速** 0.5–2 倍、**画面比例**（原始 / 裁剪 / 拉伸）、亮度与音量滑条；
- **VR 视频模式**：球面 / 180° / 鱼眼 / 平面 / 3D 左右 / 3D 上下，陀螺仪 + 触摸视角，FOV 缩放与重置；
- **锁定**：防止误触，锁定后仅显示解锁按钮；
- 控件 3 秒自动隐藏（暂停时常显），全屏横屏沉浸式播放。

### AI 实时字幕（需 PC 端 Nexus）

播放时把音频实时推流到局域网 PC 端 [FunScriptCast-Nexus](https://github.com/wanfneg/FunScriptCast-Nexus/releases/latest)，由 PC 完成语音识别 + 翻译，实时显示**中文字幕**。

使用方法：

1. PC 上安装并运行 Nexus（翻译模型与识别档位均在 PC 端配置；术语表已随 Round 53 从服务端移除）；
2. App「设置」→「AI 字幕」，确认服务地址（默认 `http://192.168.2.2:8756`，请改成你 PC 的 IP）；
3. 播放页顶栏点 **AI** → 选择识别语言（**日语 / 英语**）即可开启；
4. PC 端模型冷启动时画面自动暂停等待（画面上显示等待进度，最长 90 秒），模型就绪后自动续播。

特性：

- 同一视频再次观看时命中 PC 侧字幕缓存，全片字幕秒出；
- 与文件字幕（CC）互斥，开启 AI 字幕自动关闭 CC；
- 显示样式沿用「字幕样式」设置；
- 仅内置播放器提供（联动模式读不到头显音频）；字幕比画面晚数秒属正常现象。

## 四、预设模式（无需脚本）

「预设」页内置 **24 种动作模式**，全部中文命名，按实际播放节奏下的动作特点命名，每张卡片绘制真实波形并显示「循环 Ns」配速标签（当前速度下一个循环的时长，拖速度滑块实时变化）。

- **原版组（7 种）**：标准往复 / 峰谷连环 / 温柔正弦 / 深浅跌宕 / 轻挑细捻 / 极限冲刺 / 强拍律动
- **脚本挖掘组（17 种）**：拉链爬升 / 长波缓涌 / 深抽连颤 / 拱形中浪 / 低吟渐起 / 连击长落 / 细密渐强 / 冲顶碎颤 / 中幅爆发 / 锯齿大落 / 密颤变奏 / 呼吸起伏 / 逐级推移 / 蓄势突进 / 全幅大浪 / 潮汐涨落 / 匀速全抽

控制方式：

- **预设速度**：1–500（绝对速度，100 = 原始节奏，500 = 最快）；
- **BOOST**：一键狂暴加速（速度拉满 500）；
- **RANDOM**：每个循环结束自动随机切换到另一个预设；
- **播放 / 暂停**；
- **设备行程**：限制输出范围 0–100%（双滑轨），浅尝或保护设备均可。

脚本模式与预设模式互斥，切换时 App 会弹窗确认。

### 待机缓动

设备空闲（既没有脚本在播、也没有手动操作）达到设定秒数后，自动开始轻柔往返运动；一旦有播放等外部动作即让位，播放暂停时挂起、恢复后继续。

- 「视频」/「联动」页的 **待机缓动卡**：开关、运动范围与速度，运行中调节实时生效、不中断运动；
- 「设置」页：空闲判定秒数（默认 5 秒）；
- 勾选「关联输出」后，缓动范围跟随主行程限制。

### 一键急停 / 一键爆发

- **一键急停**：立即停止一切运动，按钮变为「一键继续」，点击恢复；
- **一键爆发**：以 0–100% 满速冲刺，期间脚本同步暂停；可设置为跟随主行程范围。

## 五、脚本加载规则

播放时 App 按以下顺序自动查找与视频 / 音频**同名**的 `.funscript`：

1. **同目录**：与媒体文件同一目录下的同名脚本；
2. **脚本文件夹**：设置页设定的本地脚本文件夹（支持多层子目录，同名即可、不必同目录）；
3. **远程脚本源**：「连接」页配置的 WebDAV / SMB / DLNA 脚本仓库兜底。

也可以在「设置」页 **手动选择 .funscript 脚本**。

### 远程脚本源

脚本集中放在 NAS / PC 时很有用：「连接」页 →「远程脚本源」→ 选协议（WebDAV / SMB / DLNA）→ 连接并浏览，选中脚本目录保存。首次使用会并行枚举建立索引并缓存到本地，之后播放秒级命中、自动下载脚本。DLNA 方式使用 PC 端 Nexus 的 DLNA 服务即可。

## 七、常见问题

**连接播放器成功但没有动作？**
依次检查：VR 播放器远程控制是否开启；IP / 端口是否正确；「设置」里脚本文件夹是否已设定且包含**同名**脚本；「联动」页脚本状态是否显示脚本名（而非"无对应脚本"）。

**AI 字幕一直显示"正在启动 PC 端模型"？**
确认 PC 端 Nexus 正在运行；手机与 PC 在同一局域网；「设置 → AI 字幕」里的服务地址是否为 PC 的实际 IP。

**远程视频 / 脚本加载慢？**
建议授予「所有文件访问」权限；SMB 已针对大文件跳转优化（拖动进度条到中后段明显更快）；脚本走远程脚本源时首次建索引后即有本地缓存。
